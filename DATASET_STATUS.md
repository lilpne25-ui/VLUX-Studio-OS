# DATASET STATUS V0.4

El dataset separa activos audiovisuales (`videos`) de publicaciones (`publications`) y métricas por plataforma (`platform_metrics`). EP011 tiene una publicación de Instagram registrada desde una captura proporcionada por el usuario. No hay MP4 asociado todavía.

No se mezclan métricas sintéticas con métricas observadas de usuario. Las plataformas y fechas se almacenan por separado; una fecha desconocida permanece NULL.
