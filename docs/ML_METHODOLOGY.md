# ML Methodology

VLUX Studio OS is human-in-the-loop.

1. Import authorized assets and record provenance.
2. Extract objective features and clearly marked proxies.
3. Capture human pairwise preferences.
4. Attach verified publication and commercial observations.
5. Run the rules baseline.
6. Train a lightweight candidate only when the dataset supports it.
7. Hold out complete episodes or campaigns.
8. Compare baseline and candidate.
9. Review limitations and approve manually.

The current state is:

```text
NO_TRAINING_INSUFFICIENT_DATA
```

This is an honest safety state, not a failure. There are not yet enough independent labels or commercial outcomes for a defensible model.
